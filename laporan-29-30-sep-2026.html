Alur End-to-End

1. INCOMING — Barang dari Supplier
↓
Web: Arrival → Receive (tag FIFO) → catat lokasi rak
↓
2. STOK TERSEDIA di Gudang
↓
Web: Incoming → Stock (lihat stok per tag + rak)
↓
3. PRODUCTION PLAN — WO dijadwalkan
↓
Web: Set target D/D+1/D+2
APK Warehouse: Papan material (kebutuhan hari ini)
↓
4. ISSUE OUT — Warehouse
↓
APK Warehouse: Scan tag stok → scan rak → Release WO
↓
5. PENERIMAAN MATERIAL — Production BARU
↓
APK Production: Scan tag material → scan QR mesin → konfirmasi
Web: Monitoring penerimaan per mesin (live Echo)

Catatan: Langkah 1–4 dilakukan di web atau APK Warehouse. Langkah 5 adalah fitur baru yang memisahkan peran warehouse dan production ke APK berbeda.

Catatan Deployment

  1. Pull ERP: git pull && php artisan migrate --force
  2. Seed: php artisan db:seed --class=RolesAndPermissionsSeeder --force
  3. Seed lokasi: php artisan db:seed --class=LocationSeeder --force
  4. Clear cache: php artisan optimize:clear
  5. APK Warehouse: Install dist/MaterialTracker-1.0.1+4.apk (atau build ulang untuk +5)
  6. APK Production: Install build/app/outputs/flutter-apk/app-release.apk
